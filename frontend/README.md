# ScamShield Bharat - Frontend

This folder will contain the frontend development of the ScamShield Bharat web application.

## Planned Frontend Screens

- Landing Page
- Login Page
- Registration Page
- Dashboard
- Message Analysis Page
- URL Analysis Page
- Risk Analysis Result Page
- Analysis History Page
- User Profile Page

## Frontend Technology

- React.js
- HTML
- CSS
- JavaScript

## Frontend Responsibilities

The frontend will allow users to:

- Register and login
- Submit suspicious messages
- Submit suspicious URLs
- View risk scores
- Understand detected risk indicators
- View recommended safety actions
- Access previous analysis history
